# 0015 — DocC・ADR が書いた約束の 1 文を、境界と陰性対照で突く物差しを別に立てる

## 状態

採用 (2026-10-11)

## 文脈

物差しの多くは mokume `v0.16.2` で止まっている。v0.17〜v0.22.1 では、作品が外とやりとりする口がまとめて入った。

- ファイルを読む口: CSV・文字 (`loadTable`・`loadStrings`・`saveTable`)、JSON・XML (`loadJSONObject`・`loadXML`)、
  SVG (`loadShape`)、STL (`loadModel`)
- 時刻を操る口: `pauseTime`・`playTime`・`jumpTime`
- 通信の口: OSC・UDP・TCP・WebSocket
- 粒の向き: `Emitter`・`Heading`

これらの口は 1 度も突かれていない。しかも、これまでの物差しの型に収まらない。

- 破れの多くは画素に出ない。読んだ値・投げた失敗・届いたメッセージ・知らせの行に出る。
- 同じ結果になるはずの別経路が、mokume の中に無いことが多い。
- 代わりに、DocC が 1 文ではっきり約束している。「1 つの datagram が 1 つのメッセージになる」
  「`1e400` のように `Double` に収まらない数は読めない」「`0 0 0` の面は両面として扱う」などである。

## 決定

**物差し `Clause` を足す。**

- **既存の物差しに足さず、別の 1 本にする。** ADR-0003・0005・0008・0011・0014 と同じく、当たりの出どころ
  (約束の文) と判定の型 (値・ファイル・ポート・知らせ) が違う。もう 1 つの理由は版である。新しい口は `v0.16.2` の
  物差しには置けず、その物差しを上げるのは別の版上げの関心事になる。
- **判定は、約束の 1 文がいう値を、そのまま確かめることにする。** 期待には必ず出典を付ける。
  DocC・ADR、Processing / p5.js の同名の口、SVG や CSS など外の規格のどれかである。
  - 外の規格だけが出典で、mokume の説明が何も言っていない食い違いは、起票しない。
    例: 幅 0 の viewBox、読めない `preserveAspectRatio`。
  - 実装のコメントが意図だと書いている振る舞いも、起票しない。例: `M x y z` の丸い端。
  - これらは README の「起票しなかったもの」に残す。
- **再現そのものを検査にする。** 破れは mokume だけで閉じた再現 (`Repros/`) が出し、`ReprosTests` が `withKnownIssue`
  で包む。陰性対照 (破れない隣の条件) と境目は、各再現の中で先に確かめる。崩れていたら `control broke` を返す。
  これで、突く側が突けていないのに破れと数える取り違えを防ぐ。
- **破れなかった約束のうち、境目を押さえるものは `ControlsTests` に常に緑で置く。** 例: CSV の往復、JSON の入れ子の上限。
- **画素の指紋は読まない。** 絵を読む再現 (SVG・立体) もあるが、判定は画素の数か明るさの閾値で行う。
  決定論の比較は他の物差しが押さえているので、`scripts/stress.py` の対象には入れない。
- **通信はループバック (127.0.0.1) だけで確かめる。** 外のホストへは送らない。
- **版は `v0.22.1` で始める** (測る版で始める)。他の 12 本の版は変えない。

## 影響

- mokume `v0.22.1` で 7 領域を突き、18 件が約束を破っていた。18 件とも main (`e7af450`) でも単独で出たので、Bug として
  起票した。そのうち面の向きの 2 件は同じ根 (向きの有無をモデル単位の 1 つの印で決めている) に見えたので、
  根の Issue (mokume#2342) で束ねた (docs/filing.md の 7)。
- 粒の向き (`Emitter`・`Heading`) は 0 件だった。分布・繰り越し・変換とも DocC のとおりだった。
- 約束の文が無いか極端な値でしか出ない 9 件は、起票しなかった。README に観察として残す。
