# 0011 — 機能を組み合わせたときだけ崩れる継ぎ目を、1 つずつの合成と比べる物差しを別に立てる

## 状態

採用 (2026-09-26)

## 文脈

これまでの物差しは、それぞれ 1 つの機能か 1 つの条件を見ていた。

- Probe は継ぎ目。
- Drift はフレームをまたぐもの。
- Aftermath は失敗の後。
- Imprint は書き出し。
- Soak は資源。

mokume には、**1 つずつなら正しく動くのに、組み合わせると崩れる**バグの型がある。1 つずつの検査を
全部通っても残るので、これまでの物差しには掛からない。

v0.12.0 のソースを読むと、崩れ方は 3 つの型に分かれていた。

1. **状態の一部だけが、別の経路に届く (または届かない)。** 同じ関数の中で、片方の経路 (粒の CPU の経路) は
   面と塗りを張り直し、もう片方 (既定の GPU の経路) は張り直さない。
2. **共有の写しを、別の組み合わせが上書きする。** 粒の置き場所の写し、断片が覚えている面。
3. **フレームの途中の描き切りで、後段の仕組みが前半を取りこぼす。** 影の焼き付け、周囲の背景。

#26 の観点の地図に近い 2 本がある。#22 (条件の格子と関係による判定) と #23 (呼び出し列のファジング) である。
ただし、どちらもこの型を狙ってはいない。#22 は条件を振り、#23 は列を生成する。どちらも、状態を共有する継ぎ目を
読んで当てるわけではない。

## 決定

**物差し `Weave` を足す。**

- **既存の物差しに足さず、別の 1 本にする。** 理由は 2 つある。
  - 当たりの出どころ (状態を共有する継ぎ目) が違う。
  - 判定の型 (組み合わせ ↔ 1 つずつの合成) が違う。

  ADR-0003・0005・0008 と同じく、「何件を突いて何件が破れていたか」を混ぜずに数える。
- **判定は、組み合わせて 1 回で描いた経路 (`suspect`) と、同じ機能を 1 つずつ使って合成した経路
  (`reference`) の比較にする。** 合成の書き方は、候補ごとに関係として決める。例は次のとおり。
  - 塗りだけの図形の上に、輪郭だけの図形を重ねる。
  - 別の粒の群を使う。
  - 読み取りの行を抜く。
  - 切り抜きの中の `background` を、同じ色の矩形に置き換える。

  mokume の同じ口の別経路には、なるべく頼らない。頼るときは、その経路が約束どおりに描くことを、実装の
  説明か ADR で確かめる。
- **比べる許容はほぼ 0 にする** (成分の差 0.004)。ただし、経路の違う同じ図形を比べる候補は、縁を 50% の被覆で
  白黒にした形で比べる。縁の濃さは経路で違ってよく、一致するのは形である (mokume ADR-0039 決定 1)。
- **陰性対照を置く。** 組み合わせても崩れないものを 0 画素差で押さえ、舞台と比べ方が効いていることを示す。
- **参照が描けていることの押さえは、`withKnownIssue` の外に置く。** 参照まで描けていないことを、既知の問題に
  数えないためである。
- **約束の出典が書けるものだけを破れと数える。** 出典は次のいずれかとする。
  - 説明文
  - ADR
  - 実装のコメントが名乗る約束
  - 手本 (Processing・p5)

  手本と同じ振る舞いや、説明から期待が一意に決まらないものは突かず、README に理由を残す。
- **落ちる組み合わせは、画素では判定しない。** 見つけたら mokume へ戻し、プロセスの終わり方の検査は Soak に
  任せる (ADR-0008 と同じ分け方)。
- **形は Aftermath を踏襲する。** 1 経路 = 1 本のスケッチで、経路ごとに別の `SketchRuntime` で回す。窓は
  1 候補ずつ左右に並べる。
- **版は `v0.12.0` で始める** (他の物差しと同じく、測る版で始める)。

## 影響

- mokume `v0.12.0` で 19 件を突き、16 件が約束を破っていた。16 件とも Bug として起票した
  (mokume#1643–#1658)。陰性対照の 3 件は 1 画素も違わなかった。
- 突いている途中で、落ちる組み合わせを 1 つ見つけた (`createShape` の中で、置いた描き場所を描き換える)。
  mokume#1588 と根が同じなので、入口として足した。
- 画素を見る物差しなので、`Stage.swift` で読んだ絵は `fingerprint` を通す。`scripts/stress.py` の対象にも
  入れた (ADR-0007)。
- 版上げでは、他の物差しと同じく「赤くなった `withKnownIssue` は直った約束」として読む
  (`.claude/skills/probes-bump/`)。
