# Routine — 作品がふつう書く書き方を、動かして突く

**作品ではなく物差しである。** Probe と Drift は mokume の**ソースを読んで**当たりを付けた。
Routine はその逆で、**mokume の中身を読まずに**、クリエイティブコーディングの作品が当たり前に
書く「単純な機能の組み合わせ」を 25 通り選び、**フレームを重ねて**期待どおりに動くかを確かめる。
重箱の隅ではなく、作品の 1 本目が踏む書き方を狙う。

## 何をしているか

**候補 1 件を、同じ動きになるはずの 2 つの経路で描く。**

- **左 (`suspect`)** は、作品がふつうに書く書き方をそのまま通す。
  - 例: `setup()` で色と `rectMode` を 1 度だけ決め、`draw()` は描くだけ。
  - 例: 押している間だけ `line(pmouseX, pmouseY, mouseX, mouseY)` を引くお絵描き。
- **右 (`reference`)** は、同じ動きを疑いの入らない書き方で作る。
  - 例: 毎フレーム設定し直す。
  - 例: 同じ 2 画を `line` で直に引く。解析解の色を塗る。

左右が食い違えば、どちらかが期待と違う。

| 確かめ方 | 何を通るか | 何で見るか |
| --- | --- | --- |
| `mokume run .` | 候補を 1 件ずつ大きく並べる (← → で切り替え) | 目で見る |
| `swift test` | 窓を出さない経路。`SketchRuntime` を経路ごとに組み、N 枚回す | 画素を読んで数で比べる |

**1 経路 = 1 本のスケッチで、経路ごとに別の `SketchRuntime` で回す。** Drift は 1 枚の面に
タイルを並べたが、ここはそれができない。候補の多くが「`setup()` で決めた描き方が残るか」
「面全体を薄める」「面の画素を読む」なので、面を分け合うと隣のタイルが疑いに混ざる。
窓も同じで、経路ごとの `SketchRuntime` が描いた絵を読み戻して本体へ貼る。読み戻しが
1 経路あたり約 10 ms かかるので、窓は全部を並べずに 1 候補ずつ見せる。

**時計はフレーム番号から導かれる** (`SketchRuntime` の既定)。`frameRate` 30 なら n 枚目は
(n − 1) / 30 秒。**入力を使う候補も、窓の操作ではなく出来事の台本で動く**
(`runtime.input.enqueue`)。そのため窓とテストは同じ絵の列を見る。

**各検査は、疑いを確かめる前に参照の側が動いていることを押さえる** (色が出る・動く・
薄まる)。**約束どおりだった候補も、疑いの側を 1 か所壊すと赤くなることを確かめてある**
(25 件すべて)。

候補の定義は [`Sources/Routine/Habits.swift`](Sources/Routine/Habits.swift) の 1 か所にだけ
あり、窓もテストも同じ定義を描く。

## 走らせる

```bash
mokume run .                                 # 窓で 1 候補ずつ見る (← → で切り替え)
swift test                                   # 窓を出さずに回して、画素で比べる
ROUTINE_DUMP=/tmp/routine swift test         # 比べた最後の絵を PNG で書き出す
ROUTINE_FRAMES=/tmp/frames swift test --filter writeFrames   # 窓の絵を候補ごとに 1 巡ぶん書き出す
ROUTINE_FRAMES=/tmp/frames ROUTINE_ONLY=pmouseStroke swift test --filter writeFrames
```

**`swift test` は緑で終わる。** 期待と違ったものは `withKnownIssue` で包んであり、
「既知の問題」として数えられる (`v0.11.1` では 25 本のテストで 1 件)。

## 結果 — mokume `v0.11.1`

**25 件を突いて、約束を破っていたものは 0 件だった。** 期待と違ったのは 3 件で、
いずれも mokume が説明や ADR で決めている振る舞いだった。そのうち 1 件は説明に書かれて
いないので、docs として起票した。

**作品が当たり前に書く組み合わせは、動かしても崩れなかった。** Probe と Drift が
ソースを読んで見つけた破れ (14 件) は、どれも継ぎ目の奥にあった。

### 説明が欠けていたもの (起票した)

| 鍵 | 何が起きたか | mokume |
| --- | --- | --- |
| `trailBackground` | p5 の残像の書き方 `background(0, 20)` が残像にならない。2 枚目で白い四角が消え、面全体が (0, 0, 0, 0.078) で置き換わる。`background` は「このフレームをここから描き直す」塗り直しなので筋は通るが、説明は 2 つ目を「不透明度」とだけ書き、Processing (無視する) とも p5 (重ねる) とも違う | [#1550](https://github.com/mokume-metal/mokume/issues/1550) (docs) |

### 原典と違うが、約束どおりのもの (起票しなかった)

| 鍵 | 何が起きたか | 起票しなかった理由 |
| --- | --- | --- |
| `negativeSize` | `sin()` で揺らして負になった幅の `rect` / `ellipse` / `circle` は何も描かない。Processing は反対側へ伸ばし、p5 の楕円は絶対値を取るので、`circle(x, y, 50 * sin(t))` は脈打ち続ける | `rect` の説明が「幅か高さが 0 以下になる指定では**何も描かない**」と約束している。`ellipse` / `circle` も同じ規則に従う。テストはいまの振る舞いを押さえる |
| `polylineTrail` | `beginShape` / `vertex` で引いた太い折れ線だけ、縁がなめらかでない (被覆が 0 か 1)。`line` の線分はなめらか | **mokume ADR-0039 の決定 3** が「三角形の経路 (立体・任意形状) の縁の AA はいまは足さない」と決めている。決定 1 が約束する「幾何の一致」(50% で白黒にした形・面積・重心) は満たしていたので、テストはそちらを押さえる |

### 約束どおりだったもの

| 鍵 | よくある書き方 | 確かめたこと |
| --- | --- | --- |
| `styleCarry` | `setup()` で色・線・`rectMode`・`ellipseMode`・`imageMode`・`tint`・`textSize`・`textAlign`・`strokeCap` を 1 度だけ決める | 毎フレーム設定し直した絵と、1 枚目も 3 枚目も区画ごとに一致 |
| `transformReset` | `draw()` で `translate` / `rotate` / `scale` を戻さずに使う | 10 枚目が 1 枚目と、`resetMatrix()` した絵と 1 画素も違わない |
| `trailFade` | `fill(0, 20); rect(全面)` で残像を薄める | 白が (1 − 20/255)^n の解どおりに薄まり、90 枚目で 0.005 未満まで消えきる (8 bit の面で残る薄い残像は出ない) |
| `midFrameRead` | 描いた直後に `get()` / `loadPixels()` + `pixels` で読み、`pixels` へ書いてから上に描く | 同じフレームの色が読め、書いた画素の上に後の図形が重なる |
| `layerComposite` | 毎フレーム `background(.transparent)` で塗り直す描き場所に半透明の円を重ねて貼る | 本体へ直に描いた絵と一致し、前のフレームの円も残らない |
| `pulseScale` | `scale(s)` で脈打たせた枠と線 | 線の太さも s 倍になり、座標と太さを s 倍して直に描いた絵と一致 |
| `spinnerArc` | 回し続けるローディングの `arc(t, t + 1.5π)`。1 時間ぶん回った角 (≈ 18850 rad) と負の角 | 2π で割った余りの角の弧と一致 |
| `nanShape` | 零ベクトルの正規化などで、円・線・頂点・幅に NaN や ∞ が混ざる | 同じフレームの他の図形も、次のフレームも巻き込まない |
| `growingCount` | 図形の数がフレームごとに増え (100 → 25600)、途中で減る (3000) | 光った画素の数が置いた数とちょうど一致 |
| `glyphChurn` | 毎フレーム漢字 240 字とカウンタを端数の大きさで描き、最後に "Hello" へ戻る | 最後の "Hello" が、最初から "Hello" だけを描いた絵と 1 画素も違わない |
| `pmouseStroke` | 押している間だけ `line(pmouseX, pmouseY, mouseX, mouseY)` を引き、背景は 1 度だけ | 離していた間の移動が線にならず、2 画とも書き始めから引ける |
| `dragDelta` | `mouseDragged(deltaX:deltaY:)` の量で棒を回す (1 フレームに移動 3 件) | 引数の合計が `dragX` の合計と一致し、別の場所で押した瞬間の飛びは入らない |
| `keyHeld` | 押し続けた矢印キーで動かす。途中で OS のキーの繰り返しが届く | 押していたフレーム数ぶんだけちょうど進み、離すと止まる |
| `pauseToggle` | スペースで `noLoop()` / `loop()` を切り替える一時停止 | 止めている間は絵が残り、再開すると `frameCount` の続きの絵になる |
| `seedPerFrame` | `draw()` の頭で `randomSeed` / `noiseSeed` を撒き直す。描いた後で別の用途に `random()` を引く | 30 枚目まで 1 枚目の配置と 1 画素も違わない |
| `blendCarry` | `blendMode(.add)` にしたまま戻さずに終える | 次のフレームの `background` は足し算にならず、塗り潰す |
| `shapeReuse` | `setup()` で `createShape` した星を、毎フレーム動かして 20 か所に置く | その場で頂点を並べた絵と一致 |
| `setupLayer` | `setup()` で描き場所に 1 度だけ下絵を描き、毎フレーム貼る | 30 枚目まで中身が残る |
| `pixelFeedback` | 背景を塗らず、`pixels` で前のフレームの絵を読んで 1 px ずらして書き戻す | 1 フレーム 1 px ずつ動き、ずらした位置に直に描いた絵と一致 |
| `textCenter` | 毎フレーム桁の変わる数字を `textAlign(.center)` で置く | `x − textWidth / 2` に左揃えで置いた字と重心が 0.3 px 以内 |
| `tintFade` | 白い絵を `tint(255, a)` で溶け込ませる | 同じ色の四角を `fill(255, a)` で塗った濃さと一致 |
| `depthNoBackground` | 3D で背景を塗らずに回す | 奥行きはフレームごとに消え、奥の箱が前のフレームの手前の箱の絵の上に出る |

## どうやって当たりを付けたか

**mokume の実装は読んでいない。** 候補は、Processing・p5 の作品が当たり前に書く形から
選んだ。

- **フレームの境目**: `setup` で決めた描き方、戻さない変換・混ぜ方、毎フレームの種
- **残像と層**: 半透明の重ね塗り、透明に塗り直す層、`setup` で焼く下絵、背景なしの 3D
- **画素**: 描いた直後の読み戻し、前のフレームを読むフィードバック
- **揺れる値**: `scale` の脈、負になる大きさ、増え続ける角、NaN
- **量**: 増えて減る図形の数、入れ替わり続ける字形
- **入力**: `pmouse` のお絵描き、引きずって回す、押し続けるキー、一時停止

mokume から読んだのは、名前を知るための**公開 API 一覧** (リリースの
`mokume-api-v0.11.1.md`) だけである。**食い違いが出た後で**、それが約束の破れか設計かを
分けるために、その関数の説明文と、説明が指す ADR を読んだ。

### 当てたが突かなかったもの

| 当たり | 突かなかった理由 |
| --- | --- |
| Retina 向けの `pixelDensity: 2` で、`width`・線の太さ・描き場所の位置が論理の座標のまま出るか | mokume の `pixelDensity` は Retina の意味ではない。**描く細かさを出す細かさより下げる倍率** (MetalFX の拡大の前段) で、説明が「使えるのは 0 より大きく 1 以下」と書き、組み立てで `invalidPixelDensity(2.0)` を投げる。説明どおりである |

## どの mokume で測ったか

**`Package.resolved` が固定している版がそのまま答えで、コミットしてある** (`v0.11.1` =
`a714449`)。`from: "0.11.1"` は他の物差しと同じく記録であって、留め金ではない。

版を上げたら `swift test` を回す。**赤くなったテストは、直った約束か、変わった振る舞いである。**
いまの振る舞いを押さえている 3 件 (`trailBackground` の置き換え・`negativeSize` の空白・
`polylineTrail` の幾何) は、mokume が説明や ADR を改めると赤くなる。
